## 1. Deskripsi Proyek
Proyek ini dibangun untuk memenuhi penugasan Sesi 6 mata kuliah **Pemrograman Berbasis Platform**. Aplikasi ini menyajikan halaman arahan (*Landing Page*) profil pengembang personal yang di-host menggunakan web server **Express.js** dan berkas antarmuka **HTML5** modern.

## 2. Struktur Direktori Proyek
```text
session6_landing_page/
├── index.js                  # Entry point web server Express.js
├── package.json              # Metadata proyek & dependencies
├── package-lock.json         # Lockfile npm
├── public/                   # Berkas statis
│   ├── index.html            # Antarmuka profil developer (Tailwind CSS)
│   └── images/
│       └── avatar.png        # Foto profil pengembang
└── README.md                 # Dokumentasi proyek
```

## 3. Cara Menjalankan Server Lokal
1. Instal dependensi:
   ```bash
   npm install
   ```
2. Jalankan server:
   ```bash
   npm start
   ```
3. Buka peramban di: `http://localhost:3000`
